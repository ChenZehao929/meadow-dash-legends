The PNG files in this folder are a curated local copy from the pack's PNG
folders. The game uses them as optional visual assets and includes Canvas
fallback drawings so it remains playable if a file is unavailable.

Used roles:
- tiles/grassMid.png, grassLeft.png, grassRight.png: grass platforms
- tiles/brickBrown.png, boxCoin.png: brick and question blocks
- tiles/backgroundGrass.png: optional background reference
- characters/playerStand.png, playerWalk.png, playerJump.png, playerCrouch.png: player frames
- characters/slimeBlue_move.png, slimeBlue_dead.png: enemy frames
- items/coinGold.png, mushroomRed.png, bush.png: pickups and scenery
- items/flagRed1.png, flagRed2.png: finish flag frames

No proprietary Nintendo assets, logos, music, or sounds are included.

The crouch frame is the pack's `alienBlue_duck.png`, downloaded from:
